USE IT · YOUR OWN CUDA CODE

Log in, write CUDA, run it on the GPU

$ cd ~/cuda/examples
$ cuda-dev make
$ cuda-dev ./matmul 2048
$ cuda-dev ./pi 1000000000
$ cuda-dev # shell with nvcc

nvcc, cuBLAS, cuRAND, cuFFT run in a rootless container on the persistent partition. The host stays read-only, with no compiler.
