ARCHITECTURE

Power on: the OS configures the GPU by itself

UKI

our 6.12 LTS kernel + initramfs + cmdline in one EFI file

initramfs

squashfs root read-only. /etc on tmpfs, /var and /home on persist ext4

gpu-autoconfig

finds the GPU in sysfs, loads the open modules, persistence mode, CDI spec, Dynamic Boost

health check

one CUDA benchmark run in a rootless container, as user “bench”

login

banner with GPU status + result; gpu-status, gpu-watch, cuda-dev

ON THE HOST

Driver userspace only: libcuda, NVML, GSP firmware, nvidia-smi, Container Toolkit, nvidia-powerd. No CUDA toolkit, no compiler.

IN CONTAINERS

Health check: binary + cuBLAS runtime (466 MB, in the image). cuda-dev: nvcc + CUDA libraries (on the persist partition).

The benchmark is a boot-time health check, not a loop. The user gets a normal console and SSH, and runs their own code through cuda-dev.
