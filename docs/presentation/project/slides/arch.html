ARCHITECTURE

From power button to running CUDA in about 20 seconds of userspace

UKI

Debian 6.12 LTS kernel + initramfs + cmdline in one EFI file, chainloaded by GRUB

initramfs

squashfs root read-only. /etc overlay on tmpfs, /var and /home overlays on persist ext4

gpu-autoconfig

sysfs PCI scan → load open modules → device nodes → CDI spec

trackc-bench

user “bench” → rootless Podman → CUDA container, GPU via CDI

dashboard

live NVML metrics + latest results on tty1

ON THE HOST

Driver userspace only: libcuda, NVML, GSP firmware, nvidia-smi, Container Toolkit, nvidia-powerd. No CUDA toolkit, no compiler.

IN THE CONTAINER

Benchmark binary (cudart static) + cuBLAS runtime only. Built multi-stage; nvcc stays in the build stage.

The host only drives the GPU. CUDA itself lives in the container. Persistence mode and Dynamic Boost are on, so the GPU behaves like on stock Ubuntu.
