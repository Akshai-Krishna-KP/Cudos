A FINDING ON THE WAY

The first custom build was 12% slower on the GPU. The OS wasn’t the cause.

STOCK, DYNAMIC BOOST ON

228 GB/s

nvidia-powerd running (Ubuntu default)

STOCK, DYNAMIC BOOST OFF

200 GB/s

same laptop, same binary, service stopped

FIRST CUSTOM BUILD

200 GB/s

no nvidia-powerd: GPU dropped to P3/P4 with “SW thermal slowdown”

Fix: ship NVIDIA’s 6 MB nvidia-powerd plus D-Bus. Proved by an A/B test on stock Ubuntu before changing our image.

Raw data: docs/results/phase8/powerd-experiment-baseline.txt, custom-dev-laptop2-no-powerd/

NVML telemetry showed the custom image in lower P-states with thermal-slowdown flags even though it ran cooler. Stopping nvidia-powerd on stock Ubuntu reproduced exactly 200 GB/s. Lesson: "minimal" must not drop the power-management daemon on laptops.
